# Instica app releases

Release files for the Instica app for Mac. Download the current version:

https://github.com/pinestraw/instica-app-releases/releases/latest/download/Instica.dmg

The installed app checks this repository's latest release for updates. Instica for iPhone and iPad is on the
App Store, and Instica for Windows is on the Microsoft Store.

This repository holds release files only. For help, see https://app.instica.com/support.
